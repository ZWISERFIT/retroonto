# C-NO-FABRICATION: no-fabricated-diagnosis

| 字段 | 值 |
|------|-----|
| **严重程度** | 🔴 |
| **约束** | 禁止编造诊断结论 — 外部系统配置/状态的声明必须附带验证证据 |
| **来源** | ERR-005 (2026-04-28 飞书编造事件) |
| **生成日期** | 2026-07-10 |

## 规则
1. 任何诊断结论必须包含：证据来源 + 验证方式 + 验证时间戳
2. 禁止"铁定是""肯定是""一定是"类绝对化表达——除非已验证
3. 区分"SDK输出" vs "我的推理"：只报告实际输出，推理标注为推测
4. 无法获取的数据→标注"暂无接入"
5. 违规→立即公开承认 + 写入违规记录

## 关联
- 铁律三：汇报数据须附带来源和生成时间
- ERR-005
- ERR-003 (同样源于未验证就断言)
