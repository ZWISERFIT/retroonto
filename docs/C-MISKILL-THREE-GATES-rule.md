## 三管齐下
1. **冷静期:** 任何检测到"异常"必须连续3次确认后才触发操作
2. **通知机制:** 任何kill/restart/stop操作前必须发Agent-Bus通知+等待15秒确认
3. **回滚方案:** 每次变更前：写入changelog+备份旧配置+写回滚方案
